# tools

木子澄安診所　工作台：臨床計算、減重報告、衛教圖卡、列印表單整合在同一個頁面。

線上版：<https://adigu2025.github.io/tools/>

| 路徑 | 內容 | 單獨開啟 |
|---|---|---|
| `index.html` | 工作台外殼（四個分頁、衛教圖卡、列印表單） | <https://adigu2025.github.io/tools/> |
| `calc/` | 臨床計算與自我評估（原 muzi-calc repo） | <https://adigu2025.github.io/tools/calc/> |
| `weight/` | 減重治療全面評估系統（原 weight repo） | <https://adigu2025.github.io/tools/weight/> |
| `img/` | 傷口照護、檢查類衛教與檢查治療同意書圖片 | |

臨床計算與減重報告在工作台裡以 iframe 嵌入，三者同網域，工作台才能統一外觀、讀取結果、一鍵清除。
兩個子資料夾 2026-10-15 以 git subtree 併入，原本的修改紀錄都保留在這個 repo。
