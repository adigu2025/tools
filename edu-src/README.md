# 衛教圖卡原始檔

工作台「衛教圖卡」部分圖片的版面原始檔。改文字時改這裡，再重新輸出圖片。

## 檔案

| 檔案 | 用途 |
|---|---|
| `cards.html` | 自製圖卡的完整版面：減重「用藥 02 用藥注意事項」，以及檢查與治療類的 5 份（胃鏡檢查前、瘜肉切除術後、冷凝刀治療後、抗逆流結紮術後、幽門桿菌除菌）。版型比照減重「療程」系列 |
| `patch.html` | 減重「療程 03 內視鏡減重治療」「療程 04 回診時程」「用藥 01 減重藥物怎麼選」沒有版面原始檔，這裡在原圖上蓋白後重寫改過的字 |
| `orig/` | 上面 3 張的原圖（修改前），`patch.html` 一律從這裡開始改，重跑不會疊加 |

減重其他圖卡（認識肥胖 01 至 04、療程 01、02、用藥 03）沒有原始檔。傷口照護、頭部外傷與腹部超音波衛教由另一位醫師負責，不在這裡修改。

## 輸出步驟

1. 啟動能接收存檔的本機伺服器（`consent-src/serve.ps1` 只服務 `consent-src/out/`；在 tools 資料夾用任一支援 `POST /__save?name=` 的伺服器，把檔案存到 `edu-src/out/`）。
2. 打開 `cards.html`，主控台執行 `fitReport()`，每頁數字都要大於 0（等於 0 代表內容壓到頁尾）。
3. 執行 `await renderAll()`，或只輸出其中幾張：`await renderAll(['edu-hp-eradication'])`。輸出 1241 × 1755 的 WebP。
4. `patch.html`：打開後等 3 秒，主控台執行 `await saveAll()`。
5. 把 `out/` 的圖片複製到工作台的 `img/`，`sw.js` 的快取版號加一，新增或改名時改 `edu/edu.js` 的 `EDU_LIST`，並更新 `revision.js`。

## 規則

- A4 直式；頁首左邊「木子澄安診所　○○衛教」，右邊系列與編號（例如「治療後 01」），側欄依這個編號排序。
- 頁尾版本標示 `v. 年/月`，改內容時一起改。
- 「立即就醫」放粉紅框，「請先討論」「除菌之後」這類提醒放米色框。
