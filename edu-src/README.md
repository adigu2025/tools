## 輸出步驟

1. 啟動能接收存檔的本機伺服器（`consent-src/serve.ps1` 只服務 `consent-src/out/`；在 tools 資料夾用任一支援 `POST /__save?name=` 的伺服器，把檔案存到 `edu-src/out/`）。
2. 打開 `cards.html`，主控台執行 `fitReport()`，每頁數字都要大於 0（等於 0 代表內容壓到頁尾）。
3. 執行 `await renderAll()`，或只輸出其中幾張：`await renderAll(['edu-glp1-guide-1'])`。輸出 1241 × 1755 的 WebP。
4. `patch.html`：打開後等 3 秒，主控台執行 `await saveAll()`。
5. 把 `out/` 的圖片複製到工作台的 `img/`，`sw.js` 的快取版號加一，新增或改名時改 `edu/edu.js` 的 `EDU_LIST`，並更新 `revision.js`。

## 規則

- A4 直式（A5 版為 A4 上半部，安全邊界上左右 10 mm、下 13 mm，名詞不可因換行切斷，必要時用 `<br>` 或 `<span class="nw">`）；頁首左邊「木子澄安診所　○○衛教」，右邊系列與編號（例如「治療後 01」），側欄依這個編號排序。A5 頁尾只寫一行地址、電話、版本（診所名稱已在頁首）；頁首、頁尾字級和 A4 相同（11.5px，編號 15px）。
- 頁尾版本標示 `v. 年/月`，改內容時一起改。
- **右下角（以後新做的也一樣）**：A5 衛教單只放官方 LINE QR code；A4 單張只放診所 LOGO（`img/logo-mark.png`），不放文字，位置固定為 1241 × 1755 像素的右緣 x 1118、上緣 y 1648、高 66 px（`cards.html` 的 `.mark`、`patch.html` 的 `MARK`）。
- 同類的衛教排在相鄰編號（例如瘜肉切除術後、大腸瘜肉追蹤是治療後 01、02），新增一張時插在同類旁邊，後面的編號往後移，並同步 `edu/edu.js` 的側欄順序。
- 新的 A5 衛教單一律做在 `a5.html`，複製現有一張的結構改內容，`fitReport()` 每欄都要 4 以上。
- 「立即就醫」放粉紅框，「請先討論」「除菌之後」這類提醒放米色框。
